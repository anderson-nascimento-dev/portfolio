# Portfolio

Personal portfolio site for Anderson Nascimento, built with Next.js, React, and Tailwind CSS.

## Edit content

Everything on the page comes from one file: `data/portfolio.ts`.
Update your name, links, experience, selected work, skills, education, and certificates there.

- To show a GitHub link, set `profile.github`.
- The resume served at `/Anderson_Nascimento.pdf` lives in `public/`. Replace the file to update it.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Deploy

The site is fully static. It deploys as-is to Vercel, Netlify, or any host that supports Next.js.
